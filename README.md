An enterprise-grade, high-performance Order & Catalog Management backend and administrative system designed to integrate directly with [Modern Storefront](https://github.com/newesp/modern-storefront) over a shared **Supabase PostgreSQL** database architecture.

## 🌟 Architectural Overview

```

|                       Modern Storefront (React 19 / Vite)                     |
|                                                                               |
|  - Customer Browse & Cart                                                     |
|  - Checkout RPC (create_demo_order)                                           |
|  - Supabase Auth & Storage (product-images, product-files)                    |
+---------------------------------------+---------------------------------------+
                                        | (Shared PostgreSQL)
                                        v
+-------------------------------------------------------------------------------+
|                         Shared Supabase PostgreSQL DB                         |
|                                                                               |
|  - products (UUID, text[] image_paths, is_digital, price NTD integer)         |
|  - orders & order_items (UUID PK, line_total generated stored)                |
|  - profiles (display_name, role) & auth.users                                 |
|  - public.admin_customer_view (Read-only joined presentation view)            |
|  - admin_users & integration_logs (Admin auth & telemetry)                    |
+---------------------------------------+---------------------------------------+
                                        ^
                                        | (Direct PDO / Eloquent)
+---------------------------------------+---------------------------------------+
|                    OrderFlow Lite (Laravel 11 Admin Panel)                    |
|                                                                               |
|  - Executive Dashboard & Metric Aggregations                                  |
|  - Product Catalog CRUD & Active Toggling                                     |
|  - Customer Lifetime Value & Order History                                    |
|  - Order Operations & Directional State Machine                               |
|  - Integration Telemetry & Resilient Webhook Pipeline                         |
|  - Blade SSR + Modern Tailwind UI + RESTful JSON APIs                         |
+-------------------------------------------------------------------------------+
```

## 🚀 Key Features

1. **Direct Supabase Schema Compatibility**:
   - **UUID Primary Keys**: Uses string UUID identifiers natively across `products`, `orders`, and `profiles`.
   - **Integer Monetary Values**: Enforces NTD currency as strict PostgreSQL integers across all layers (no float rounding errors).
   - **PostgreSQL Array Normalization**: Seamlessly reads and updates `products.image_paths` (`text[]`).
   - **Storefront RPC Alignment**: Full compatibility with orders generated by `create_demo_order`.

2. **Unified Customer Read Model**:
   - Utilizes `public.admin_customer_view` to read customer records without altering Supabase Auth isolation.
   - Calculates aggregate metrics (lifetime order count, total completed spend).

3. **Deterministic Order Lifecycle State Machine**:
   - Strict transition rules (`pending -> processing/cancelled`, `processing -> completed/cancelled`, terminal `completed` and `cancelled`).
   - Domain exception handling (`InvalidOrderStatusTransitionException`) mapped to HTTP 422 JSON and flash alerts.

4. **Integration Telemetry & Webhook Pipeline**:
   - Emits internal audit logs for order mutations.
   - Dispatches outbound webhooks with built-in retry and non-blocking failure tolerance.

5. **Evaluation-Ready Admin Authentication**:
   - Dedicated `admin_users` table with session auth guard.
   - Built-in **1-Click Auto-Fill Demo Credentials** button on the login screen.

## 🛠️ Installation & Local Setup

### Prerequisites
- PHP 8.3+ (with `pdo_sqlite`, `pdo_pgsql`, `mbstring`, `fileinfo`, `zip`)
- Composer 2.x
- Node.js 20+ & npm

### Setup Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/newesp/laravel-orderflow.git
   cd laravel-orderflow
   ```

2. **Install PHP & Frontend Dependencies**:
   ```bash
   composer install
   npm install
   npm run build
   ```

3. **Configure Environment**:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **Run Migrations & Seed Database**:
   ```bash
   # Seeds demo admin and catalog products
   php artisan migrate --seed
   ```

5. **Start Local Development Server**:
   ```bash
   php artisan serve
   ```
   Open [http://localhost:8000/admin](http://localhost:8000/admin) in your browser.

## 📡 REST API Reference

All administrative API endpoints are prefixed with `/api/admin` and protected by the `auth:admin` guard.

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/admin/login` | Authenticate admin credentials |
| `POST` | `/api/admin/logout` | Invalidate admin session |
| `GET` | `/api/admin/me` | Current authenticated admin profile |
| `GET` | `/api/admin/products` | Paginated product list with search/filters |
| `POST` | `/api/admin/products` | Create a new catalog product |
| `GET` | `/api/admin/products/{id}` | Get product details |
| `PUT` | `/api/admin/products/{id}` | Update product details |
| `PATCH` | `/api/admin/products/{id}/status` | Toggle product active status |
| `DELETE` | `/api/admin/products/{id}` | Delete product |
| `GET` | `/api/admin/customers` | Paginated customer list with order stats |
| `GET` | `/api/admin/customers/{id}` | Customer profile & order history |
| `GET` | `/api/admin/orders` | Paginated orders list with status filters |
| `GET` | `/api/admin/orders/{id}` | Order snapshot details and line items |
| `PATCH` | `/api/admin/orders/{id}/status` | Transition order lifecycle status |
| `GET` | `/api/admin/integration-logs` | Telemetry audit trail and webhook logs |
